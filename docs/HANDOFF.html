5. 训练 / 评测命令(可直接复制)

5.1 8 卡平台:真训练 baseline P0

提交训练任务时,挂当前镜像(或保存的镜像)+ /mnt/volumes/ad-perception-al-sh02/... 数据卷,然后执行:

USE_GLOBAL_PYTHON=1 bash /mnt/volumes/ad-perception-al-sh02/liuqingyu854/Track/Sparse4D-V3/scripts/03_train_baseline.sh

选项含义:

  • USE_GLOBAL_PYTHON=1:跳过 venv 查找,直接走系统 /usr/local/bin/python3.11
  • 脚本内部已 export CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 + dist_train.sh 8
  • config 默认 num_gpus=8 × samples_per_gpu=6 = total_batch_size=48,100 epoch,~12-18h
  • 每 20 epoch 自动 eval + 存 ckpt,共 5 个 ckpt(在 work_dirs/baseline_v3_r50_repro/)

7. Phase 1 改进计划(跟踪增强)

按 docs/research/sparse4dv3_improvement_plan.md 的 ROI 排序,5 个 trick 推荐这个顺序接入(每加一个跑一次 8 卡训练验证 ablation):

顺序编号名称来源论文实现成本预期收益
1.1 B5 ContrasTR loss ContrasTR (WACV 2024) 🟢 低(纯 loss 加法) +1-3% AMOTA,IDS 降低
1.2 B1 PF-Track Spatial-Temporal Reasoner PF-Track (CVPR 2023)(本地已有 ../PF-Track/) 🟢 低(代码可复用) +3-5% AMOTA,IDS 降 50%
1.3 B7 Birth/Death 状态机(替代 prev_id++ 暴力分配) Poly-MOT (IROS 2023) 🟢 极低 IDS 进一步降低
1.4 D1+D4 Hierarchical Query Denoising + 物理约束 DN noise S2-Track (ICML 2025) 🟢 低 +2-3% AMOTA
1.5 B3 Uncertainty-aware Probabilistic Decoder S2-Track 🟡 中(改 attention) +2-3% AMOTA

Phase 1 接入工作流

  1. 新建实验分支(规范见 §10):git checkout -b lqy/exp/<trick> main
  2. 从 baseline config 复制一份:cp projects/configs/sparse4dv3_temporal_r50_1x8_bs6_256x704.py projects/configs/expN_<trick>.py
  3. 改 flag 启用 trick(在 Phase 0 末段准备好的 flag 框架里)
  4. 8 卡训练:CONFIG=projects/configs/expN_<trick>.py bash scripts/03_train_baseline.sh
  5. 评测 + 与上一个 baseline 对比
  6. 结果 ≥ 论文 ablation 预期 → merge 回 main + 进下一个 trick;不达标 → debug 或 revert

8. Phase 2 改进计划(多模态融合)P2

Phase 1 完成后,引入 LiDAR 提升上限:

组件来源实现要点
LiDAR backbone VoxelNet (CenterPoint 同款) / PointPillars BEV feature 输出,256 通道
跨模态 sampling FUTR3D MAFS (CVPRW 2023) 替换 DFA,query 同时从 image + BEV 采样 + 自适应加权
位置编码 CMT (ICCV 2023) image token 用 frustum 3D,LiDAR token 用 BEV;在 3D 空间对齐
Masked-modal training CMT 训练时随机 drop modality,容错
显式深度监督(可选) BEVDepth (AAAI 2023) 替换 DenseDepthNet,用 LiDAR GT 监督

预期:NDS 0.72+, mAP 0.65+, AMOTA 0.70+(对标 TransFusion-CL,但端到端跟踪)

9. 历史踩坑速查(新集群避免重复)

#报错根因修法 / 状态
1 The detected CUDA version (12.1) mismatches the version that was used to compile PyTorch (11.7) 用 torch 1.13+cu117 编 CUDA op 时,系统 nvcc 12.1 不兼容 必须用 cu121 的 torch wheel(torch 2.3.1+cu121 已在镜像里)
2 test.py: error: unrecognized arguments: --local-rank=0 torch 2.x launcher 把 --local_rank 改成 --local-rank commit e059c6c 已修(argparse 双别名)
3 'MMDistributedDataParallel' object has no attribute '_use_replicated_tensor_module' mmcv 1.7 跟 torch 2.x DDP 实现脱节 _apply_compat_patches.sh 已 patch(系统镜像 mmcv 1.7.0 已 patched)
4 AttributeError: 'int' object has no attribute 'type' (in _get_stream) torch 2.x 的 _get_stream 需要 torch.device _apply_compat_patches.sh 已 patch
5 cannot import name 'Iterable' from 'collections' motmetrics 1.1.3 用了 Py3.10+ 移除的 alias _apply_compat_patches.sh 已 patch
6 module 'inspect' has no attribute 'getargspec' motmetrics 1.1.3 用了 Py3.11 移除的函数 _apply_compat_patches.sh 已 patch
7 ModuleNotFoundError: No module named 'projects.mmdet3d_plugin'(系统 python) 系统镜像里某 Meta 库的 projects/__init__.py 屏蔽了 Sparse4D 的 namespace package commit ed1c511 新增 Sparse4D 自己的 projects/__init__.py
8 deformable_aggregation needs to be set up CUDA op 没装,或 venv/系统的 torch 版本不同 .so ABI 不兼容 setup_env_global.sh 自动 install 到 site-packages;源码 import 用 try/except 兼容两种位置
9 AttributeError: module 'numpy' has no attribute 'int' Sparse4D 源码用了 deprecated np.int,numpy 1.24+ 已移除 commit 4234179 改成 np.int64
